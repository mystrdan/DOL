# Dawn of Longlat (DOL)

> An original game universe inspired by the diverse mythological traditions of Africa.

Dawn of Longlat is a mobile-first game project built around an original fictional world: Longlat.

## Core principle

**Research first. Fiction second.**

DOL will draw inspiration from many African traditions while keeping those traditions culturally distinct. Historical and ethnographic material will not be presented as if Africa has one single mythology.

## Project pillars

- A living world
- Pan-African inspiration
- Respectful adaptation
- Original fiction
- Mobile first
- Player first
