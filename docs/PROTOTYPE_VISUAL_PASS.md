# Prototype Visual Pass

## Goal
Improve readability and hierarchy without turning the prototype into final art.

## Player should immediately read
1. where they are;
2. where the route continues;
3. what can be interacted with;
4. what is unusual;
5. what is dangerous.

## Zone treatment

### Settlement
Use simple building masses, an open yard, the guide NPC, and a clear exit. Prioritize signs of ordinary life over decorative detail.

### Old Road
Make the road the strongest navigation line. Use a wider traversable strip, subtle ground contrast, a landmark marker, and a clear bend toward the river.

### River
Show continuous water, banks, and a readable crossing point. It should feel like an environmental feature before anything supernatural happens.

### Community / Sacred Landscape
Create a quieter space before the Veil with a clear natural focal point and restrained visual language. Final real-world references require a research record first.

### Damaged Veil
Make it the first unmistakably supernatural element. Prefer spatial distortion, brief displacement, restrained contrast, and environmental change. Avoid giant portals, magic circles, excessive particles, or generic purple rifts.

### Combat Clearing
Give the first fight enough room to read. Keep the enemy visible before contact and preserve space for dodging.

## HUD hierarchy
Objective → immediate status → health → contextual dialogue → debug information.

Debug information should eventually be hidden behind a development toggle.

## Interaction hierarchy
See → approach → prompt → act → feedback.

The old road marker is the first test of this pattern.

## Definition of done
A first-time tester can identify the settlement, road, river, community/sacred landscape, Veil, and combat area without developer explanation.
