# DOL Player Onboarding

## Goal

Teach the player by letting them act.

## First Five Minutes

The player should learn:

- movement;
- camera;
- interaction;
- environmental observation;
- objective tracking.

No combat tutorial wall of text.

## Tutorial Principle

**Show → Let Player Try → Confirm → Remove Assistance**

Example:

1. Player approaches an object.
2. Interaction prompt appears.
3. Player interacts.
4. Game responds.
5. Prompt disappears.

## Combat Tutorial

Do not pause the entire game for a tutorial card.

Teach through a safe encounter:

- enemy approaches;
- player sees telegraph;
- dodge is useful;
- enemy recovers;
- player attacks;
- enemy reacts.

## Objective UI

Keep it short.

Good:

**Investigate the old road**

Bad:

**According to the ancient cosmological history of Longlat...**

## Cultural Information

Lore can be discovered voluntarily.

Possible channels:
- conversations;
- environmental details;
- optional records;
- story scenes;
- later codex.

Do not require the player to read a mythology encyclopedia to understand combat.

## Mobile

Touch controls should remain readable.

Prototype:
- movement;
- attack;
- dodge;
- interaction.

Avoid filling the screen with buttons.

## Accessibility

Plan early for:
- readable text;
- adjustable text size where feasible;
- clear attack telegraphs;
- audio cues paired with visual cues;
- reduced visual clutter.

## Success Test

A first-time player should be able to reach the first Veil without developer instruction.
