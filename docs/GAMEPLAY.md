# DOL Gameplay Foundation

## Status
Phase 0 — Game Design Foundation

Dawn of Longlat is a game first. Research supports the game; it does not replace building it.

## 1. Target Experience

DOL is a mobile-first action-adventure game with exploration, readable combat, discovery, character progression, and a strong story.

The player should understand the basic loop within minutes:

**Explore → Discover → Fight/Interact → Gain something → Learn more → Push deeper**

The first playable build should prove this loop before adding large systems.

## 2. Core Pillars

### Movement
Fast, responsive movement with a small number of actions that feel good on touch controls.

### Exploration
Compact environments with readable paths, secrets, environmental clues, NPC encounters, and supernatural disturbances.

### Combat
Real-time combat designed around clarity rather than button complexity.

Initial combat verbs:
- Light attack
- Heavy/charged attack
- Dodge
- Guard/parry or equivalent defensive action
- Context interaction
- One player ability

The exact input layout remains prototype-dependent.

### Discovery
The player learns through:
- environmental details;
- dialogue;
- encounters;
- objects;
- short lore entries;
- optional discoveries.

Lore should never interrupt normal play unnecessarily.

### Progression
The first build uses simple progression:
- player health;
- basic combat improvement;
- one or two meaningful abilities;
- story progression;
- optional discoveries.

Avoid skill-tree bloat during the first prototype.

## 3. Game Loop

### Minute-to-minute

1. Move through an area.
2. Notice something unusual.
3. Investigate or continue.
4. Encounter a threat or obstacle.
5. Resolve it through combat, movement, or interaction.
6. Receive a small reward or new information.
7. Decide where to go next.

### Session loop

**Start → Explore → Encounter → Progress → Save → Return**

The first prototype should be enjoyable even before the full story exists.

## 4. First Playable Region

Working name: **Longlat Marches**

The region should contain only enough content to demonstrate the game's identity:

- Longlat outskirts
- small settlement or homestead area
- road/trade path
- river or water crossing
- forest/vegetation edge
- damaged sacred/supernatural site
- first Veil
- first enemy encounter
- short return path or progression gate

This is a vertical slice, not the entire first game.

## 5. First Vertical Slice

The first vertical slice should answer one question:

> **Is DOL fun to play?**

Required sequence:

1. Player enters the Longlat Marches.
2. Basic movement is taught naturally.
3. Player discovers the first abnormal sign of the Dawn.
4. Player encounters one ordinary environmental obstacle.
5. Player reaches the damaged Veil.
6. First supernatural enemy appears.
7. Player learns the basic combat loop.
8. Player defeats or escapes the threat.
9. A short story reveal establishes that the disturbance is spreading.
10. Player reaches a safe point and can continue or restart.

## 6. What Is NOT Required Yet

Do not block the prototype on:

- a complete continent;
- dozens of mythological traditions;
- a final pantheon;
- multiplayer;
- crafting;
- open-world scale;
- complex inventory;
- procedural generation;
- large skill trees;
- monetization;
- dozens of playable characters;
- full voice acting.

## 7. Cultural Design Rule

A real-world cultural or mythological element must have a documented source/context record before being turned into a major gameplay mechanic.

DOL-original mechanics are allowed and encouraged.

The game should feel culturally grounded without turning every researched element into a mechanic.

## 8. Success Test

A prototype passes when a new player can:

- move without confusion;
- understand what they are trying to do;
- complete a short encounter;
- understand the basic combat verbs;
- recognize that something supernatural has changed;
- finish the slice without needing a lore lecture;
- want to play the next section.

## Development Rule

**Build the smallest fun version first. Expand only after it works.**
