# DOL Cultural Asset Reference System

## Purpose

Prevent the art pipeline from accidentally turning research into an unsourced visual collage.

## Every Meaningful Reference Gets a Record

For a culturally specific asset, record:

- **Asset ID**
- **Asset type**
- **Community/context**
- **Region**
- **Historical period**
- **Source**
- **Alternative names**
- **Observed variation**
- **What is directly documented**
- **What is interpretation**
- **What DOL changes**
- **Why DOL changes it**
- **Gameplay/story purpose**
- **Representation risks**
- **Review status**

## Asset Types

- architecture;
- household object;
- tool;
- agricultural equipment;
- transport;
- clothing;
- textile;
- ornament;
- food/cooking equipment;
- musical instrument;
- religious/community space;
- landscape feature;
- weapon;
- writing/symbol system;
- character appearance.

## Status

### RESEARCH
Reference collected, not approved.

### VERIFIED
Context and source checked.

### ADAPTED
Fictionalized for DOL with documented changes.

### ORIGINAL
Created by DOL.

### REJECTED
Not suitable for use.

## Hard Rule

A visual reference is not automatically culturally accurate because it appears in a museum, Pinterest board, AI image, game, film, or social media post.

The original context must be investigated.

## Community Variation

If two communities use different forms of an object, retain both records rather than averaging them into one “African” version.

## Sacred Material

Sacred/religious objects receive additional review.

Do not automatically turn them into:
- weapons;
- loot;
- armor;
- skill icons;
- crafting ingredients;
- collectibles.

## Art Pipeline

**Research → Reference Record → Concept → Review → Model/Texture → In-Game Test**

## Minimum Prototype

The vertical slice does not require hundreds of references.

Start with a small verified set for:
- settlement structures;
- road/transport;
- household life;
- agriculture;
- clothing;
- religious/community spaces;
- river environment.

## Quality Test

An artist should be able to answer:

> “Where did this design decision come from?”

without saying:

> “It just looked African.”
